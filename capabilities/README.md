# Capabilities

Reviewed Skills, Tools and scientific contracts belong here. The native Harness
remains authoritative for Agent execution, permissions and persistence.

- [Domain scope](DOMAIN_SCOPE.md): target expertise, present evidence boundaries,
  domain-specific acceptance and exclusions.
- [Knowledge and skill construction plan](KNOWLEDGE_PLAN.md): the first delivery
  sequence, provenance requirements and promotion rules.

These documents define the development scope; they do not register executable
skills or declare the selected SDK capable of every listed task. Existing
capability probes, scientific records and the pinned MCP integration remain the
sources of execution evidence.
