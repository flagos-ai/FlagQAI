## Deliberate replacements

- The old `AgentRunActivity` implementation becomes a native-event summary inside
  the existing work disclosure. Reading restoration, completed history and user
  follow controls retain their current owners.
- The old `SynthesisIteration` component is replaced by saved optimization-pair
  selection and actual evidence comparison. Pairs require the same recorded run;
  an unrelated historical baseline cannot be presented as a valid optimization.
- The defensive arithmetic monolith is replaced by clean example copies, runtime
  preflight and versioned official catalog evidence. Do not reinsert compatibility
  scaffolding into a user's scientific source.
- The old navigation stylesheet is folded into the current rail. Shared surfaces
  are extracted selectively; obsolete selectors and earlier component layouts are
  excluded.
- Candidate, baseline and synthesis test modules from the prototype are covered
  by the current HTTP API, worker, preflight and projection suites. The existing
  strict path, digest, revision and execution guards are retained.
- The one-off `reproduce_invsqrt.py` recorder requires external competition data
  and metric code and is not the reviewed production verification path. Its
  experiment remains available in the original workspace. No alternate execution
  service is introduced by copying it into the package.
- Existing reviewer records retain relative evidence references. Replacing them
  with personal absolute filesystem paths would reduce portability without adding
  an independent trial.
