# FlagQAI CLI bundled guide

This guide is installed with FlagQAI CLI. Start with `getting-started.md` or
`getting-started.en.md` for installation and provider setup. Other chapters
cover terminal interactions. The commands are `flagqai` and `fq`. The npm package has not been published yet, so do not recommend a
registry install of `@flagqai/cli`.

Release availability: the default FlagQAI splash uses a wordmark, and its
version plate reads `FlagQAI v<version>`. Optional Deepy, whale-girl, and
portrait image assets are not shipped; inherited skin settings use built-in
art fallbacks. Do not describe upstream raster animations as installed features.

The 10 topic chapters, each in two languages, are in this skill's
`resourceBase`, under `guide/flagqai-guide/`. Each topic has a Chinese file
without a language suffix and an English file ending in `.en.md`. If you need
to locate the directory, search for `guide/flagqai-guide` in the installed
FlagQAI package.

Read one or two relevant chapters, using a keyword search and bounded reads
for long files. Answer in the user's language and cite the chapter and section.
If the guide does not establish a behavior, say so rather than treating an
inherited FlagQAI instruction as a verified FlagQAI workflow.

| Question | Chapter |

For English questions, append `.en.md` to the chapter's base name; for
example, use `user-guide.en.md`. The chapter copies are generated byte-for-byte
from `docs/` by `scripts/build-guide.mjs`; edit the source chapters there.
